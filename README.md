# Clinic Flow — Patient Management App
### Built on Salesforce | LWC | Flows | Rive Animations

## The Problem
Small clinics in India manage appointments, prescriptions, 
and patient follow-ups through WhatsApp and paper registers. 
This leads to missed appointments, lost records, and zero 
visibility for clinic owners on how their business is performing.

## The Solution
A Salesforce-based clinic management app that handles the 
complete patient journey — from booking to follow-up — with 
automated reminders, a doctor's daily schedule view, and an 
owner dashboard showing real-time clinic performance.

## Features
- Patient registration and history tracking
- Appointment booking with automated reminders
- Doctor's daily schedule LWC component
- Prescription management
- Patient feedback collection
- Owner dashboard with key metrics
- Custom UI with Rive animations
