## 1- Contact Number (Fieldtype- Phone)
Need: To be used to inform the doctor automatically about any update on the status of the appointment if needed.

## 2- Doctor Name (Fieldtype- Text)

## 3- Email (Fieldtype- Email)
Need: To be used to automatically send email updates about any new or cancelled appointments.

## 4- Slot Duration( Fieldtype- Number)
Need: Slot duration is to be used to determine how long will each appointment last and then to be used in Formula 
in other objects to reserve a timeslot.

## 5- Specialization (Fieldtype- Picklist)
Need: To be used to map the right Doctor on the right patient according to the needs of a patient automatically using flows.

## 6- Working Days (Fieldtype- Picklist(Multi-select))
Need: To be used to book the appointments on the day doctor is available.

## 7- Working Start Time (Fieldtype- Time)
Need: To be used to book an appointment in the time frame in which doctors are available.
